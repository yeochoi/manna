# TabBar

Today and Journal.

- Phones. A bottom bar on `surface` with a `line` on top. Line icons at 24 with `small` text. The current tab is `green-text`, the other `muted`. Labels stay regular.
- Laptops. A top bar `topbar` tall, Manna in `title` on the left, tabs in `body` on the right. The current tab is `green-text` with a 2 `primary` underline.
- Tapping the current tab scrolls the page to the top.
