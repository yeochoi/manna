# Button

The one forward action on a screen, full width on phones.

- Main fills `primary` with white `title` text, `size-button` tall, `radius-pill`.
- Outline is `surface` with a `line` border and `green-text`. Used as the second choice, like starting from Genesis 1.
- Small is 44 tall with `body` semibold, for actions inside a card.
- Reset uses `coral-text` as its fill and only appears inside the confirm panel.
- Disabled is the button at 50 percent opacity.
