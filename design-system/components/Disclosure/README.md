# Disclosure

The Passage row. One row everywhere, so people learn it once.

- No card. Hairlines above and below. The head has a `section` header and a 16 `chevron`. Open, it has 20 above the text and 12 below. Closed, 20 above and below. The whole row is the tap area.
- Open by default while you read today, closed after you finish and on past days in the Journal. If you close it while reading, it stays closed and keeps your place.
- When open, a round listen button sits 8 after the word Passage, centered on it, as its own button so tapping it never closes the passage. It reads verse by verse with the phone's voice, highlights the current verse in `soft` and keeps it in view. While reading it shows pause. Hidden while closed.
- Inside, each chapter starts with its name in `green-text` `title`. Chapter names have 14 below them, so a highlighted verse never touches them. A 36 gap above each later chapter separates them. Verses use `reading`, verse numbers are `green-text` `small`.
