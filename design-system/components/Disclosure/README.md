# Disclosure

A card that opens in place, used for the full passage.

- `surface` card with `radius-card`. The head is `size-disc` tall with a `title` and a 16 `chevron` pointing down.
- Open, the chevron points up. No line under the head, the chapter name below already starts the content.
- Inside, each chapter starts with its name in `green-text` `title`, as a heading. No hairline. A 36 gap above each later chapter separates them. Verses use `reading`, verse numbers are `green-text` `small`.
- Closed by default. It remembers being open for the rest of the visit.
